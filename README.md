# Link & File Presentasi

Repository ini digunakan sebagai pusat akses untuk file presentasi, catatan, dan link penting agar mudah dibuka dari perangkat mana pun.

## Cara Menggunakan
- Buka repository ini dari browser.
- Pilih mata kuliah atau topik yang ingin dibuka.
- Klik file PDF/PPT jika ingin mengunduh atau melihat file.
- Klik link Canva, Notion, GitHub Pages, atau link lain jika materi disimpan di luar repository.

## Tips Pengelolaan
- Gunakan nama file yang rapi dan konsisten, misalnya `presentasi-jaringan-dasar.pdf`.
- Pisahkan file berdasarkan mata kuliah atau topik.
- Simpan link Notion sebagai mode publik baca saja jika ingin dibagikan tanpa izin edit.
- Gunakan PDF untuk jaga kompatibilitas jika file akan dibuka di banyak PC.
- Perbarui README setiap kali menambah file atau link baru.

## Template Singkat untuk Menambah Mata Kuliah Baru

```md
### Nama Mata Kuliah
- File PDF: [Nama File](./presentasi/nama-folder/nama-file.pdf)
- File PPTX: [Nama Slide](./presentasi/nama-folder/nama-slide.pptx)
- Canva: [Buka Canva](https://www.canva.com/)
- Notion: [Catatan Presentasi](https://www.notion.so/)
- Link pendukung: [Nama Link](https://example.com)
```

## Catatan
- Ganti semua `username`, `nama-project`, `nama-folder`, dan link contoh dengan milik sendiri.
- Jika repository ini digunakan untuk presentasi kampus, disarankan memakai visibility **Public** agar mudah diakses dari perangkat mana pun.
